# 回归测试

在仓库根目录运行（需要 .NET 10 SDK）：

```bash
dotnet test tests/StrmTool.Tests/StrmTool.Tests.csproj
```

测试直接引用插件项目，不需要启动 Jellyfin，也不会访问远程媒体。每个用例使用独立临时目录，结束后清理。

覆盖内容：

- 新配置及缺少指纹开关的旧 XML 配置默认启用校验。
- 两个缓存读取接口在指纹匹配时命中、指纹不匹配时拒绝。
- 关闭校验可以复用缓存，但不改变原始指纹或文件内容；重新开启后仍拒绝不匹配的缓存。
- 无指纹的旧缓存不被隐式迁移；关闭校验仍会拒绝无效 JSON、无效标记及媒体流缺失等不符合对应接口要求的数据。
- 重复读取及修改返回对象不会回写文件；并发读取不会覆盖新保存的探测数据。
- 缓存读取绕过校验后，保存阶段的探测指纹一致性检查仍有效。

这些是本地缓存与配置回归测试，不替代 Jellyfin 集成测试或真实 NAS 压力测试。
